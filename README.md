# The Deplorable Book Club

Public marketing site for **The Deplorable Book Club** (GitHub Pages).

## Live URL

Once Pages is enabled: [https://rhodirish-afk.github.io/deplorable-book-club/](https://rhodirish-afk.github.io/deplorable-book-club/)

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)** → Save

No custom domain yet — do not add a `CNAME` until one is purchased and DNS is ready.

## Stack

Static HTML + Tailwind CDN + small `assets/nav.js` hamburger. Site-root links are prefixed with `/deplorable-book-club` so project Pages works at `username.github.io/deplorable-book-club/`.

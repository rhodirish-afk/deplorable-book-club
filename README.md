# The Deplorable Book Club

Public marketing site for **The Deplorable Book Club** (GitHub Pages).

## Live URL

[https://rhodirish-afk.github.io/deplorable-book-club/](https://rhodirish-afk.github.io/deplorable-book-club/)

Site-root links use the `/deplorable-book-club/` prefix for project Pages.

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)** → Save

## Stack

Static HTML + Tailwind CDN + `assets/nav.js`. Brand OG card: `assets/og.png` (1200×630; generated by the `commit-og-png` Actions workflow from brand colours/text when `assets/og.svg` or the workflow changes on `main`).

## Waitlist form

`subscribe.html` posts to FormSubmit (`myone_ie@hotmail.co.uk`). Keep the FormSubmit captcha **on** (never add the FormSubmit option that switches it off) and keep the `_honey` spam-trap field.

## Domain

The site lives only at the GitHub Pages URL above. No custom domain is registered: do not add a `CNAME` file or link to any other domain.

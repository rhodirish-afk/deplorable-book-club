# The Deplorable Book Club

Public marketing site for **The Deplorable Book Club** (GitHub Pages).

## Live URL

[https://rhodirish-afk.github.io/deplorable-book-club/](https://rhodirish-afk.github.io/deplorable-book-club/)

Site-root links use the `/deplorable-book-club/` prefix for project Pages.

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)** → Save

## Stack

Static HTML + Tailwind CDN + `assets/nav.js`. Brand OG card: `assets/og.png` (1200×630; generated by Actions workflow from brand colours/text).
